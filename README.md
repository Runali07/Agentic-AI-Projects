# 🤖 Agentic AI Projects
A collection of Agentic AI projects built using LangGraph, LangChain, Mistral AI, Groq, Tavily Search, Streamlit, and Python.
This repository demonstrates different AI workflow patterns including sequential execution, parallel processing, conditional routing, state management, and Human-in-the-Loop systems.-

## 🚀 Projects Included

### 💼 1. Human-in-the-Loop LinkedIn Post Generator

Generate professional LinkedIn posts using AI with an interactive review process.

#### Features

- LangGraph workflow
- Human approval before publishing
- Multiple rewrite iterations
- Tavily Search integration
- Mistral AI
- Streamlit UI
- MemorySaver checkpoints

**Tech Stack**

- Python
- LangGraph
- LangChain
- Streamlit
- Tavily Search
- Mistral AI
